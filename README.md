# Пансионат «Династия»

Исходный код сайта [dynastia-residence.ru](https://dynastia-residence.ru/).

## Размещение

Сайт рассчитан на обычный PHP-хостинг. Для работы формы заявки серверу нужны переменные окружения:

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_CHAT_ID` — ID чата для заявок;
- `NOTIFY_EMAIL` — почта для дублирования заявок.

Значения секретов и файл `leads.log` намеренно не хранятся в репозитории.
